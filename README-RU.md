# Мой день — iPhone, 0.2.0
Экспериментальная мобильная редакция. Не испытана в Obsidian/iOS. Это не отдельное приложение, а плагин Obsidian. Компьютер для установки не обязателен. Нужен доступ к папке хранилища через системный выбор папок iOS.

## Установка только на iPhone
1. Сохраните ZIP в «Файлы», нажмите для распаковки. Внутри полученной папки найдите my-day-phone, содержащую main.js, manifest.json, styles.css.
2. Скопируйте my-day-phone в КОРЕНЬ тестового хранилища Obsidian. Не в папку верхнего уровня Obsidian со всеми хранилищами, а внутрь конкретного хранилища.
3. Установите приложение a-Shell из App Store. Запустите, введите pickFolder и выберите это же хранилище. Приложение должно предоставить доступ к нему.
4. Проверьте команды pwd и ls -a. Должны быть видны .obsidian и my-day-phone. Если нет — ничего не копируйте, выберите правильное хранилище. При необходимости showmarks и jump "имя закладки" позволяют перейти к выбранной папке.
5. Закройте Obsidian на время копирования. В a-Shell выполните:
mkdir -p .obsidian/plugins/my-day-phone
cp my-day-phone/main.js my-day-phone/manifest.json my-day-phone/styles.css .obsidian/plugins/my-day-phone/
6. Откройте Obsidian → Настройки → Сторонние плагины, включите «Мой день — iPhone». Может понадобиться перезапуск.
Если хранилище нельзя выбрать в pickFolder, этот маршрут недоступен: не создавайте вторую папку .obsidian наугад. Способ зависит от расположения хранилища.
Установку приложения a-Shell и предоставление доступа выполняет пользователь. Плагин сам не устанавливает приложения и не меняет разрешения.

## Использование
Палитра команд → «Мой день — iPhone: Открыть мобильный экран» (ищите «мобильный экран»).
Команду можно назначить быстрым действием Obsidian. В собственном экране кнопки «Неделя» и «Заметка дня» открывают обычные Markdown-заметки.
Неделя содержит чекбоксы под ## областями. Отредактируйте примеры. Вернитесь к мобильному экрану через команду, нажмите «＋ Задача недели». 🍅 открывает два режима: 50/10 и 25/5; ⏱️ запускает секундомер.
После окончания Pomodoro ПЕРЕРЫВ ЗАПУСКАЕТСЯ ВРУЧНУЮ. Следующая работа сама не начинается. Паузы нет — завершите интервал и запустите новый. Задача не закрывается автоматически.
В дневную заметку уже вставляется блок my-day. Переключите заметку в режим чтения для интерактивных карточек. Собственный мобильный экран не зависит от режима чтения/редактирования.
Нет TaskNotes, Dataview, Bases или Templater зависимостей. Категории ручного ввода пока фиксированы: Трейдинг, Личное, Семья, Дом, Текучка, Отдых. Рабочая категория определяется заголовком ##. Нет настройки путей: файлы в «Мой день/Дни» и «Мой день/Недели».

## Данные и ограничения
Версия имеет НОВЫЙ id my-day-phone. Не мигрирует data.json из предыдущего my-day-focus. Не включайте оба плагина одновременно для одного таймера. Не удаляет заметки.
Выборка задач только из текущей недели (понедельник—воскресенье). К задачам добавляется ^md-ID. Не удаляйте ID и не копируйте его в другую задачу. Название карточки — снимок на момент добавления. Для обновления подписи уберите и добавьте задачу снова.
Дневная сумма привязана к дате начала интервала; интервалы через полночь не разбиваются. Недельная сумма привязана к файлу недельного плана, а не дате выполнения. Старые задачи в новом недельном списке не считаются теми же задачами без отдельного переноса идентификаторов.
Основной журнал/состояние — data.json в папке плагина. Читаемый журнал — дописываемые строки в дневной заметке. Редактирование Markdown не меняет data.json. Сохраняйте оба в резервной копии. Удаление data.json теряет сводки и выбор задач. Нет двустороннего импорта и восстановления по Markdown.
Только одно устройство. Фон iOS не гарантирует выполнение JS или уведомления. Звука и системных уведомлений НЕТ. При возвращении Pomodoro закрывается по плановому окончанию. Секундомер включает всё время до нажатия завершения, даже часы в фоне. Это не доказательство фактической работы.
Код не использует сеть, Node.js/Electron API. Статический аудит не заменяет тест на устройстве.

## Первый тест
В отдельном хранилище: создать неделю, добавить задачу, нажать 🍅 и проверить оба варианта, начать 25/5 и через минуту завершить. Должна появиться одна запись и сумма. Проверить секундомер, ручную запись, отказ при пересечении, сохранение после перезапуска. Проверить 25-минутное окончание, переход в фон, крупный шрифт и клавиатуру iPhone.
